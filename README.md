# AIplaygrand-Win · USB 에디션 0.4.0

Claude 2명과 Gemini 1명으로 시작하는 초보 팀의 AI 실습 공간입니다. Codex를 포함해 팀원을 추가할 수 있습니다. API 키 없이 공식 웹사이트 또는 설치된 공식 CLI를 열고, 사람이 질문을 직접 전송하고 답변을 기록합니다. 0.4부터는 설치된 공식 CLI로 **자동 3단계 팀 릴레이** 및 **1:1 앱 내 CLI 대화**를 실행할 수 있습니다. 계정 사용량을 합치거나 제한에 도달한 계정을 자동으로 교체하지 않습니다.

## 웹 팀원 이어받기 (수동 핸드오프)

- **사전 동의와 보관함 저장**: 각 팀원은 로그인 설정에서 이어받기 수신을 명시적으로 동의(기본값 꺼짐)한 경우에만 5초 뒤 자동 인계 창 열기가 적용됩니다. 동의하지 않은 팀원도 직접 이어받을 수 있습니다. 프로필별 동의 여부는 `Data/team.vault`에 암호화 저장되며 프로필 버튼에서 언제든 수정·철회할 수 있습니다.
- **수동 소진 표시와 후보 목록**: 앱은 쿼터(사용량 한도)를 자동 감지하지 않습니다. 사람이 직접 소진을 표시하면 원래 팀원은 일시중단되고 작성 중이던 부분 답변은 보존됩니다. 이번 앱 세션의 후보 목록에서 소진 표시된 프로필은 제외되며, '다시 참여'를 눌러 명시적으로 복귀시킬 수 있습니다(실제 쿼터 검증 아님). 모든 후보의 로그인 여부와 남은 사용량은 소유자가 직접 확인할 때까지 알 수 없습니다.
- **5초 타이머와 창 열기**: 동의된 대상 선택 시 5초 취소 카운트다운 타이머가 표시되며, 다른 후보를 선택하면 타이머가 초기화되고 미동의 대상은 '이어받기'을 직접 눌러 진행합니다. 취소·포커스 해제(blur)·새로고침·종료 시 카운트다운이 취소됩니다.
- **저장과 수동 전송**: 대기열의 새 미션이 먼저 저장된 후 클립보드 복사와 전용 웹 창 열기가 진행됩니다. 제공자 사이트로의 자동 전송이나 독립적인 CLI 계정 전환은 지원하지 않습니다.

## CLI 팀 릴레이 (0.4 신규)

작업 하나를 적으면 세 단계가 순서대로 실행됩니다. 기본 구성은 Claude → Gemini → Claude이며 단계마다 공급자와 역할 설명을 바꿀 수 있습니다. 각 단계는 원래 요청과 앞선 단계의 완료 결과를 함께 받습니다. **Claude Code·Codex CLI·Gemini CLI를 앱 내 대화와 릴레이에 연결합니다.** 각 CLI 설치와 별도의 서비스 이용 권한이 필요합니다.

- **자동 실행 범위는 CLI뿐입니다.** 웹 미션은 공식 사이트 질문 전송이 수동 방식이며(이어받기 시 복사·창 열기는 선택적 5초 타이머), 브라우저 자동 조작이나 웹 로그인 자동화, 제공자 자동 전송은 없습니다.
- **세 단계는 세 계정이 아니라 세 번의 CLI 실행입니다.** 계정은 이 PC의 CLI 로그인 계정이며, 같은 서비스를 두 단계에 쓰면 같은 계정을 두 번 사용합니다. 팀원별 계정 분리, 자동 계정 교체, 사용량 제한 우회를 하지 않으며 제한에 걸리면 오류로 멈춥니다. 앱은 API 키를 묻거나 저장하지 않습니다.
- **텍스트·코드 제안만 받습니다. 차단 방식은 공급자마다 다릅니다.**
  - Claude Code: `-p --output-format stream-json --verbose --include-partial-messages --safe-mode --tools "" --strict-mcp-config --permission-mode dontAsk --permission-prompts none --no-session-persistence --disable-slash-commands`. `--safe-mode`가 훅·MCP·플러그인·스킬·CLAUDE.md 등 사용자 설정을 끄고, `--tools ""`로 내장 도구가 없으며, 권한 요청은 자동 거부됩니다. 관리자 정책(managed settings)은 CLI가 계속 적용합니다.
  - Codex CLI: `exec --json --sandbox read-only --ignore-user-config --ignore-rules -c approval_policy="never" -c mcp_servers={} --ephemeral --skip-git-repo-check --cd <workspace> -`. 사용자 `config.toml`(MCP 서버·훅·프로필 포함)과 규칙 파일을 읽지 않고 승인 요청 없이 읽기 전용 샌드박스에서 실행합니다. **읽기 전용 샌드박스는 파일 수정을 막지만 읽기 전용 명령 실행까지 막지는 않습니다.** 명령 실행·파일 변경·MCP 호출 이벤트가 오면 그 단계를 중단하지만, 이는 사후 감지이며 짧은 읽기 전용 명령은 이미 실행됐을 수 있습니다.
  - Gemini CLI: 소스 확인한 `0.59.0`으로 고정합니다. 앱 전용 `GEMINI_CLI_HOME`과 정책 파일에서 `tools.core=[]`, `hooksConfig.enabled=false`, skills 비활성화를 적용하고 `--extensions none`과 미등록 임의 이름의 MCP 허용 목록으로 실행합니다. 기존 관리자 설정이 감지되면 덮어쓰지 않고 중단합니다. 사용자 질문은 JSON으로 전달하고 `@`를 Unicode 이스케이프해 CLI의 파일 첨부 전처리를 막습니다. 기존 개인 Gemini 설정·인증은 읽거나 복사하지 않습니다.
  - 릴레이는 시작 전에 설치된 CLI의 `--help`(모델 요청 없음)에서 위 옵션이 모두 있는지 확인하고, 하나라도 없으면 요청을 보내지 않고 옵션 이름과 함께 멈춥니다. 더 약한 옵션으로 대체하지 않습니다. Claude/Codex 작업 폴더는 `Data/Relay/workspace`(대화는 `Data/Chat/workspace`), Gemini는 PC의 앱 전용 로그인 폴더 아래 `workspace`입니다.
- 화면에는 CLI가 보낸 답변 본문과 단계 상태(대기·연결·답변 받는 중·저장·완료·오류·중지·중단), 실제 경과 시간만 표시합니다. 내부 사고 과정, 진행률 추정, 로그인 정보, 오류의 원문 stderr는 표시하거나 저장하지 않습니다.
- 단계마다 10분 제한, 답변 20만 자 제한, 단계 입력 15만 자 제한, 실행 1회당 저장 3MB 제한이 있습니다. 넘으면 잘라내지 않고 오류로 멈추며 화면의 부분 답변은 단계별 "이 단계 복사"로 가져갈 수 있습니다. 자동 재시도는 없으며 다시 보내려면 직접 시작을 눌러야 합니다.
- **중지**는 언제나 누를 수 있고 앱이 만든 CLI 프로세스 그룹(하위 프로세스 포함)만 종료합니다. 완료된 단계와 받던 부분 답변은 화면에 남고 저장에 성공한 범위까지 보관함에 남습니다. 앱을 닫을 때는 진행 중 릴레이를 먼저 중지하고 프로세스가 실제로 끝난 뒤에만 보관함을 잠급니다. 프로세스가 끝나지 않으면 앱을 닫지 않고 오류를 표시합니다. 다시 열면 이전 실행은 "중단됨"으로 표시되며 자동으로 이어 달리지 않습니다.
- 릴레이 기록은 최대 20개까지 `Data/team.vault`의 별도 필드에 암호화 저장됩니다. 기록이 20개이거나 보관함 여유(25MB 상한 대비 3MB)가 부족하면 새 릴레이를 시작하지 않으며, 오래된 기록을 자동으로 지우지 않습니다. 기록 삭제는 "이전 릴레이 기록" 목록에서 직접 합니다. 시작하지 않은 작업·역할 초안은 저장되지 않습니다. 0.3 보관함과 기록은 그대로 읽습니다.
- Claude/Codex는 공식 CLI의 로그인을 먼저 마치세요. Gemini는 첫 질문 시 공식 Google 로그인창이 열릴 수 있습니다. 브라우저 로그인을 지원하지 않는 환경에서는 로그인 터미널을 이용하세요. Windows에서는 npm CLI를 Node.js로 직접 실행하며 셸을 거치지 않습니다.

## CLI 1:1 대화 (앱 내 실행)

- **사용 방법**: 실행 준비에서 설치 상태를 확인하고, 필요한 경우 로그인 터미널에서 로그인한 뒤 **CLI 대화**를 누릅니다. 질문 입력 → 전송 → 앱 안에서 답변 확인 → 이어 질문하기 순서로 사용합니다. 중지와 답변 복사, 이전 기록 보기·삭제도 제공합니다.
- **지원 범위**: 호환되는 Claude Code·Codex CLI·Gemini CLI를 앱 대화창에 연결합니다. CLI가 텍스트를 보내는 시점에 화면이 갱신되므로 서비스마다 답변 표시 속도가 다릅니다. 웹 화면과 CLI 화면은 오갈 수 있지만 웹 대화를 CLI 대화로 자동 동기화하지는 않습니다.
- **맥락 유지**: 매 전송은 단일 실행(1 stage)으로 완료되며, 연속 대화는 앱이 이전 질문/답변 턴을 조합하여 task에 포함(최대 50,000자, 자동 절단 없음)해 전달합니다. 공급자를 바꾸거나 새 대화를 시작하면 이전 맥락은 명시적 확인 후 초기화됩니다.
- **계정 및 인증**: CLI 대화는 웹 팀원 프로필이 아닌 이 PC의 단일 CLI 계정으로 실행됩니다. 인증 정보는 USB 보관함으로 이동하지 않습니다. Gemini는 운영체제의 앱 데이터 폴더 아래 `AIplaygrand-Win/Gemini`에 공식 CLI가 직접 로그인·설정을 관리합니다. 이 인증·설정은 앱 보관함 암호화 대상이 아니며 새 PC에서 다시 로그인해야 합니다. 앱은 로그인 비밀번호·토큰을 읽거나 옮기지 않습니다.
- **저장**: 각 전송의 입력과 결과는 `Data/team.vault`에 암호화 저장됩니다. 이전 기록은 당시 조합한 입력과 답변으로 표시합니다. 전송 전 대화창 초안은 저장되지 않습니다. CLI 자체 인증·설정·기록은 해당 도구가 관리하며 앱 보관함과 별개입니다.

## 처음 시작하기

1. Windows x64 ZIP **전체**를 쓰기 가능한 USB 폴더에 풀고 AIplaygrand-Win.exe를 실행합니다. exe만 옮기면 실행되지 않습니다.
2. 팀 보관함 비밀번호를 12자 이상으로 설정합니다. 잊으면 복구할 수 없으니 안전한 비밀번호 관리자에 별도 보관하세요.
3. 기본 팀원의 **열기**에서 각자 공식 웹사이트에 로그인합니다. 앱은 서비스 비밀번호를 수집하지 않습니다.
4. 질문을 적고 **웹 브라우저 / CLI 대화(앱 안에서) / CLI 터미널**을 선택해 미션을 추가합니다. 웹 팀원 선택으로 CLI 로그인 계정이 바뀌지는 않습니다.
5. 웹과 터미널은 질문을 복사한 뒤 직접 붙여 넣어 전송합니다. 앱 내 CLI 대화는 입력창에 미션을 넣어 주며 **전송**을 눌러야 시작합니다. 답변을 보면서 추가 질문을 할 수 있습니다.
6. **저장하고 종료**, 별도로 연 **CLI 터미널 종료**, Windows의 **하드웨어 안전하게 제거** 순서로 마칩니다.
7. 다른 PC에서 같은 앱을 열고 보관함 비밀번호를 입력합니다. 서비스나 CLI 로그인은 다시 필요할 수 있습니다.

## 저장과 암호화 범위

앱 웹창은 카메라·마이크·위치·알림 등 사이트 권한 요청을 기본 거부합니다. 텍스트 학습용이며 음성·위치 기능은 지원하지 않습니다. 사이트의 클립보드 API가 동작하지 않으면 글을 선택해 키보드로 복사·붙여넣으세요.

| 항목 | 위치와 보호 범위 |
| --- | --- |
| 팀원·질문 초안·미션·답변·앱 웹창 쿠키·CLI 릴레이/대화 기록 | Data/team.vault 암호화 보관함 |
| CLI 릴레이 작업 폴더 | Data/Relay/workspace 빈 폴더 |
| 직전 보관함 | Data/team.vault.bak 역시 암호화 |
| CLI 설치 패키지 | Data/Tools/운영체제-CPU/ 일반 파일 |
| CLI 작업 시작 폴더 | Data/Projects/ 일반 파일 |
| 다운로드·내보낸 JSON | 일반 파일, 암호화되지 않음 |
| CLI 인증·설정·이력 | 각 공식 도구가 PC에서 관리. 보관함에 포함되지 않음 |
| 이전 버전 JSON·브라우저 데이터 | 기존 파일 보존. 자동 삭제·암호화되지 않음 |

보관함은 scrypt와 AES-256-GCM으로 보호합니다. 실행 중 복호화된 내용은 메모리에 있습니다. 악성코드가 있는 PC, 화면 녹화, 운영체제 임시 기록까지 보호하는 무흔적 실행은 아닙니다. 보관함 비밀번호를 아는 사람은 팀 전체 기록과 저장된 세션을 사용할 수 있으므로 신뢰하는 팀에서만 공유하세요.

## 로그인 이동의 범위

앱 안에서 직접 로그인한 Claude·Gemini·Codex 웹 세션의 쿠키를 암호화하고 다음 실행에서 복원을 시도합니다. 다른 브라우저의 인증정보를 가져오지 않습니다. 쿠키 복원 성공은 로그인 성공이 아닙니다. LocalStorage, IndexedDB, 기기에 묶인 인증 키, CLI 토큰은 이동하지 않습니다. 만료되거나 기기 인증이 필요한 세션은 공식 화면에서 다시 로그인해야 합니다. 실제 계정의 PC 간 로그인 유지 여부는 아직 검증되지 않았습니다.

각 웹 팀원은 별도 브라우저 세션을 사용합니다. **CLI는 팀원별 계정 격리가 아닙니다.** 해당 PC에서 공식 CLI에 로그인한 계정으로 실행되므로 계정을 직접 확인하세요. 웹 팀원 선택만으로 CLI 계정이 바뀌지 않습니다.

## CLI 설치 도움

실행 시 Node.js·npm·Git·Claude Code·Gemini CLI·Codex CLI의 설치와 버전을 점검합니다. 메모리와 USB 여유 공간도 표시합니다. 인터넷 연결과 계정 이용권은 보장하지 않습니다.

- 웹 모드는 Node.js나 CLI 추가 설치 없이 사용할 수 있습니다.
- CLI 설치에는 Node.js 20 이상과 npm이 필요합니다. 없으면 **공식 설치 안내**에서 설치하고 **다시 점검**하세요. Git은 권장 도구이며 필수 여부는 도구별로 다릅니다.
- **USB에 설치**는 확인 후 터미널에서 공식 npm 패키지를 USB의 Tools 아래에 설치합니다. 관리자 권한이나 전역 설치를 자동으로 요구하지 않습니다. 끝난 뒤 다시 점검해야 성공 여부가 확인됩니다.
- **CLI 열기**는 터미널을 여는 기능입니다. 자동 로그인·질문 전송·응답 수집을 하지 않습니다. Claude 무료 웹 계정에는 Claude Code 이용권이 포함되지 않습니다.
- PC의 Node.js와 CLI 인증은 USB만으로 모두 이동하지 않습니다. 운영체제/CPU가 달라지면 맞는 도구를 준비해야 합니다. 별도 터미널은 앱 종료 후에도 남을 수 있습니다.

이 앱의 '웹'은 공식 AI 웹사이트 실행 모드이며 독립 웹사이트 제품이 아닙니다. 일반 웹사이트만으로 다른 사이트의 로그인 쿠키를 읽거나 PC의 CLI를 실행할 수 없습니다.

## 저장 실패·백업·업데이트

정상 저장 시 직전 파일을 .bak로 보존하고 새 파일로 교체합니다. USB 쓰기 실패 시 오류를 표시합니다. 빈 기록으로 덮어쓰거나 PC 폴더로 몰래 전환하지 않습니다. USB를 연결하고 다시 저장하세요. 강제 종료·전원 차단·작업 중 USB 분리는 최근 입력 손실과 파일 손상을 일으킬 수 있습니다.

장치 분실·고장에 대비해 **종료 후 전체 폴더를 별도 저장소에 복사**하세요. 복구는 앱을 닫고 Data 전체를 먼저 복사한 뒤, 손상 원본을 별도 이름으로 보존하고 정상적인 team.vault.bak 복사본을 team.vault로 배치합니다. 백업에도 같은 비밀번호가 필요합니다.

0.2 기록은 첫 보관함 생성 시 복사됩니다. 원래 JSON과 Browser 파일은 그대로 남으므로 완전한 보호가 필요하면 새로운 폴더에서 시작하세요. 기존 파일은 임의로 삭제하지 않습니다. 0.1 기록은 이전 버전의 JSON 내보내기로 옮깁니다. 업데이트는 종료·Data 별도 백업 후 프로그램 파일만 교체하세요.

서비스별 이용 연령·계정 이용권을 지켜 사용하세요. 미성년자에게 성인용 계정을 공유하지 말고 서비스가 허용하는 보호자 관리 방식을 확인하세요. AI 답변은 팀이 함께 검토합니다.

## 개발과 검증

npm ci, npm start로 Mac에서 개발 실행합니다. node --test tests/*.test.js로 저장·암호화·실패 보존·화면 로직을 검사하고 npm run dist:win으로 Windows x64 ZIP을 만듭니다. 개발도 프로젝트 옆 Data에 저장하므로 실제 기록 대신 격리된 테스트 폴더를 쓰세요. Data·테스트·개인 기록은 패키지에서 제외합니다.

Mac 테스트와 Windows 패키징은 Windows 실기기 검증을 대신하지 않습니다. Windows 실행·설치 도우미·물리 USB 분리·실제 계정의 PC 간 로그인 복원, Windows에서의 CLI 릴레이 실행(npm 심(shim) 해석·taskkill 종료)은 별도 확인이 필요합니다. Windows에서는 CLI 본 프로세스가 먼저 끝나고 하위 프로세스만 남은 경우 앱이 그 하위 프로세스를 종료할 수단이 없어 해당 단계를 실패로 표시합니다. 릴레이는 각 CLI의 공식 비대화형 스트리밍 JSON 출력(`claude -p --output-format stream-json`, `codex exec --json -`)을 읽으며, CLI 버전이 바뀌어 출력 형식이 달라지면 완료로 인정하지 않고 오류로 표시합니다. 이 문서의 릴레이 설명은 구현 내용이며 실제 모델 요청으로 검증한 결과가 아닙니다.
