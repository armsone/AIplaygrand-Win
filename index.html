웹 · CLI 실행 준비

실행 환경을 확인합니다.

웹은 추가 CLI 설치 없이 열 수 있어요. Claude Code·Codex CLI·Gemini CLI는 설치 후 앱 안에서 대화와 릴레이를 진행합니다. 웹 로그인과 CLI 로그인은 서로 별개이며, Claude 무료 웹 계정에는 Claude Code 이용권이 포함되지 않습니다.

CLI는 PC에서 로그인한 계정(공용 CLI)으로 열리며, 팀원별 ‘독립 CLI 자리’를 추가한 경우에만 해당 자리의 격리된 설정을 사용합니다. 웹 팀원 선택으로 공용 CLI 계정이 바뀌지 않습니다. 공용 CLI는 이전할 수 없으며, 독립 CLI 자리는 카드의 ‘로그인 보관/복원’으로 암호화 보관함을 통해 안전하게 이전할 수 있습니다(macOS Claude 제외). CLI에서 만든 파일과 다운로드·내보내기는 별도 평문 파일입니다. USB를 빼기 전에 CLI 터미널도 종료하세요.

새 미션

⇄

자동 진행 · 웹 자동 전송과 팀원 자동 이어받기

웹 자동 전송은 팀원의 앱 전용 웹창(보이는 창)에서 로그인 계정 표식을 확인한 뒤 새 대화에 질문을 넣고 전송하여 답변을 관찰·저장합니다. 지원: Claude 웹 · Gemini 웹 (실제 사이트 화면 동작은 라이브 미검증 상태). 미지원: Codex 웹 (작업 화면 구조 미검증으로 수동 복사·열기만 지원). 사전 동의 필수, 진행 중 언제든 취소 가능하며, 한도 미확인 오류 시 자동으로 넘기지 않습니다. 앱은 비밀번호를 저장하거나 로그인을 대신하지 않습니다.

웹 자동 전송 상세 동작 및 관찰 기준 알아보기

새 대화 입력창에 질문을 넣고 전송 버튼을 1회 누른 뒤, 15초 안에 새 답변 노드(또는 내용 변화)나 생성 표시를 확인합니다. 이후 최대 119초 동안 답변을 관찰해 3회 연속 변화가 없으면 완료 처리합니다. 로그인·보안 확인·입력창에 남은 글·전송 확인 실패·한도 여부 불분명 오류는 멈추고 사용자 확인을 기다립니다. 관찰 중 부분 답변은 보관함에 암호화 저장되며 저장 실패 시 다른 팀원에게 넘기지 않습니다.


        

      

      

        
팀원 자동 이어받기

        

        
        

        

        

        
타이머는 이 창이 화면 앞에 있을 때만 흐르고, 창을 벗어나면 멈춰요. 이 앱의 웹창을 보고 있을 때 한도가 감지되면 이 창을 앞으로 가져온 뒤 시작하고, 앱이 뒤에 있으면 멈춘 채 기다립니다. 후보는 자동 이어받기에 동의한 팀원(웹창 또는 독립 CLI 자리) 중 사용량 소진으로 표시되지 않은 순서대로 한 번씩만 제안되며, 설정된 후보일 뿐 로그인 여부와 남은 사용량은 확인되지 않습니다. 같은 팀원을 반복하거나 자동으로 재시도하지 않습니다. 사용량 한도가 확인되지 않은 오류에서는 자동으로 넘기지 않아요. 취소는 준비 중인 전송과 이어받던 실행(이 세션이 시작한 것만)을 함께 멈춥니다.

      

      
지금은 진행 중인 자동 전송이나 이어받기가 없어요. 실행 방식을 ‘웹 자동 전송’으로 두고 미션의 ‘자동 전송으로 실행’을 누르거나, 실습 기록에서 ‘사용량 소진 · 자동 이어받기’를 누르면 여기에서 진행 상황이 보입니다.

      
이전 웹 자동 전송 기록

      
웹 자동 전송 결과는 보관함(team.vault)에 암호화 저장되고 해당 미션의 답변란에도 넣어 드려요. 질문·답변은 로그에 남기지 않습니다. 기록이 20개에 도달하면 새 실행을 시작하지 않으며 위 목록에서 직접 삭제해야 합니다.

CLI 1:1 대화 · 학습 도우미

        
      

      
Claude Code·Codex CLI·Gemini CLI에 질문하고 여기서 답변을 확인하세요. 호환되는 CLI 설치와 각 서비스의 이용 권한이 필요합니다. Gemini 첫 사용은 열리는 Google 로그인창에서 직접 로그인하세요. 앱 전용 CLI 로그인은 이 PC에만 보관되며 웹 팀원 로그인과 연결되지 않습니다.

      
기본값 ‘공용 CLI’는 웹 팀원과 별도로 이 PC에 로그인된 CLI 계정 하나를 사용합니다. 팀원별 독립 CLI 자리를 추가하면 그 자리의 공식 설정 폴더(CLAUDE_CONFIG_DIR·CODEX_HOME·GEMINI_CLI_HOME)로 격리된 로그인을 사용해요. 앱은 API 키나 토큰을 묻거나 복사하지 않습니다.
        
대화와 저장 방식 알아보기
설명·코드 제안을 받는 대화 모드입니다. 파일을 자동으로 만들어 실행하는 모드는 아닙니다. 이전 질문과 답변을 함께 보내며, 다른 AI로 바꾸면 확인 후 맥락을 비웁니다. 앱이 보관하는 전송 기록은 암호화되지만 CLI 자체 인증·설정·기록은 해당 도구가 관리합니다. 전송 전 초안은 저장되지 않습니다.

결과 범위: 텍스트·코드 제안만 받습니다. Claude Code는 도구 없음·safe-mode·권한 요청 자동 거부로 실행합니다. Codex CLI는 읽기 전용 샌드박스로 실행하며, 읽기 전용 명령이 실행될 수 있어 도구 이벤트가 오면 중단합니다. Gemini CLI는 지정 버전과 앱 전용 설정으로 도구·확장·훅을 끄고 MCP 허용 목록을 제한합니다. 화면에는 답변 본문과 작업 상태만 표시합니다. 한도 확인과 아래 동의 설정이 모두 충족될 때만 5초 후 인계하며, 그 밖의 오류는 멈춥니다.

실습 기록

      

      
미션을 열면 질문이 복사돼요. 서비스 창에 직접 붙여 넣고 전송한 다음, 답과 배운 점을 여기에 기록하세요. 사용량 제한에 도달하면 해당 계정은 쉬었다가 나중에 다시 사용합니다.

      
내 사용량이 소진됐다면 ‘사용량 소진 · 다음 팀원에게’(수동: 복사·창 열기까지)나 ‘사용량 소진 · 자동 이어받기’(자동 이어받기에 동의한 팀원에게 5초 뒤 자동 전송)로 미션을 넘길 수 있어요. 웹 자동 전송이나 CLI 대화가 서비스의 사용량 한도 안내·오류 코드로 멈추면 같은 자동 이어받기가 스스로 시작되며, 그 외 오류에서는 시작되지 않습니다. 넘길 때는 원래 요청과 부분 답변이 함께 전달됩니다.

      
질문과 답변은 실행 폴더에 자동 저장돼요. 내용을 다 정리하면 실습 기록 저장을 눌러 완료하세요.

      

      

    

    
USB로 옮기는 방법과 시작 전 안내
ZIP 전체를 USB에 풀고 실행하세요. 프로그램과 Data 폴더를 항상 함께 보관하세요. ‘저장하고 종료’로 앱을 닫은 뒤 Windows의 ‘하드웨어 안전하게 제거’를 사용하세요. 이 버튼은 USB 장치를 꺼내는 기능은 아닙니다.
팀원·질문·답변은 함께 이동합니다. 새 PC의 로그인은 다시 필요할 수 있어요. 팀 기록과 웹 쿠키는 보관함 비밀번호로 보호합니다. 다운로드·내보낸 기록·CLI 파일·이전 버전 원본은 암호화되지 않아요. 신뢰하는 PC에서 사용하고 별도 백업도 보관하세요.
Claude 개인 계정은 만 18세 이상용입니다. Gemini는 국가와 계정 종류에 따라 연령·보호자 승인 조건이 달라요. 개인정보는 질문에 넣지 말고, AI의 답은 함께 확인하세요.
