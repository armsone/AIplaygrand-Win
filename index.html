웹 · CLI 실행 준비

실행 환경을 확인합니다.

웹은 추가 CLI 설치 없이 열 수 있어요. Claude Code·Codex CLI·Gemini CLI는 설치 후 앱 안에서 대화와 릴레이를 진행합니다. 웹 로그인과 CLI 로그인은 서로 별개이며, Claude 무료 웹 계정에는 Claude Code 이용권이 포함되지 않습니다.

CLI는 PC에서 로그인한 계정으로 열립니다. 웹 팀원 선택으로 CLI 계정이 바뀌지 않습니다. CLI 인증·설정은 웹 보관함에 포함되지 않습니다. CLI에서 만든 파일과 다운로드·내보내기는 별도 평문 파일입니다. USB를 빼기 전에 CLI 터미널도 종료하세요.

02

새 미션

💬

CLI 1:1 대화 · 학습 도우미

Claude Code·Codex CLI·Gemini CLI에 질문하고 여기서 답변을 확인하세요. 호환되는 CLI 설치와 각 서비스의 이용 권한이 필요합니다. Gemini 첫 사용은 열리는 Google 로그인창에서 직접 로그인하세요. 앱 전용 CLI 로그인은 이 PC에만 보관되며 웹 팀원 로그인과 연결되지 않습니다.

웹 팀원과 별도로, 이 PC에 로그인된 CLI 계정을 사용합니다. 앱은 API 키를 묻지 않습니다.
대화와 저장 방식 알아보기

설명·코드 제안을 받는 대화 모드입니다. 파일을 자동으로 만들어 실행하는 모드는 아닙니다. 이전 질문과 답변을 함께 보내며, 다른 AI로 바꾸면 확인 후 맥락을 비웁니다. 앱이 보관하는 전송 기록은 암호화되지만 CLI 자체 인증·설정·기록은 해당 도구가 관리합니다. 전송 전 초안은 저장되지 않습니다.

준비

이전 대화 기록

대화 기록은 보관함(team.vault)에 암호화 저장돼요. 각 전송은 독립된 실행이며, 이전 대화 맥락은 앱이 조합하여 함께 전달합니다(최대 5만 자). 새 대화를 시작하거나 공급자를 바꾸면 이전 맥락은 초기화됩니다.

▶

CLI 팀 릴레이 · 자동 3단계

작업 하나를 세 CLI 단계가 차례로 이어받아요. 각 단계는 이 PC에 설치·로그인된 공식 CLI를 앱이 비대화형으로 실행하고, 응답 본문을 그대로 받아 보여줍니다. 웹 미션(위 새 미션)은 지금도 직접 붙여 넣는 수동 방식이며 이 릴레이와 별개입니다.

세 단계는 세 계정이 아니라 세 번의 CLI 실행입니다. 같은 서비스를 두 단계에 쓰면 이 PC에 로그인된 그 CLI 계정 하나를 두 번 사용해요. 팀원별 계정 분리, 자동 계정 교체, 사용량 제한 우회는 하지 않습니다. 제한에 걸리면 오류로 멈추며 직접 기다렸다가 다시 시작해야 합니다. 앱은 API 키를 묻지 않습니다.

결과 범위: 텍스트·코드 제안만 받습니다. Claude Code는 도구 없음·safe-mode·권한 요청 자동 거부로 실행합니다. Codex CLI는 읽기 전용 샌드박스로 실행하며, 읽기 전용 명령이 실행될 수 있어 도구 이벤트가 오면 중단합니다. Gemini CLI는 지정 버전과 앱 전용 설정으로 도구·확장·훅을 끄고 MCP 허용 목록을 제한합니다. 화면에는 답변 본문과 작업 상태만 표시합니다. 서비스별 한도나 오류가 발생하면 멈추며 계정을 자동 교체하지 않습니다.

이전 릴레이 기록

      
릴레이 기록은 보관함(team.vault)에 암호화 저장돼요. 기록이 가득 차거나 보관함 여유가 부족하면 시작하지 않으며 오래된 기록을 자동으로 지우지 않습니다(삭제는 위 목록에서 직접). 시작하지 않은 작업·역할 초안은 저장되지 않아 다시 열면 마지막 실행이나 기본값이 보입니다. 앱을 닫으면 진행 중이던 릴레이는 중단되고 부분 결과만 남으며, 다시 열어도 자동으로 이어 달리지 않습니다. CLI 인증·설정은 여전히 각 도구가 PC에서 관리합니다.

    


    

      

        
03
실습 기록

      

      
미션을 열면 질문이 복사돼요. 서비스 창에 직접 붙여 넣고 전송한 다음, 답과 배운 점을 여기에 기록하세요. 사용량 제한에 도달하면 해당 계정은 쉬었다가 나중에 다시 사용합니다.

      
내 사용량이 소진됐다면 ‘사용량 소진 · 다음 팀원에게’로 웹 미션을 다른 팀원에게 넘길 수 있어요. 앱은 사용량을 감지하지 않고 사람이 직접 표시합니다. 넘길 때는 원래 요청과 지금까지의 부분 답변을 담은 새 미션이 만들어지고, 이어받는 팀원이 동의한 경우에만 그 팀원의 웹창을 열고 질문을 복사합니다. 전송·로그인 확인은 이어받는 팀원이 직접 하며, CLI 계정으로는 넘기지 않습니다.

      
질문과 답변은 실행 폴더에 자동 저장돼요. 내용을 다 정리하면 실습 기록 저장을 눌러 완료하세요.

      

      

    

    
USB로 옮기는 방법과 시작 전 안내
ZIP 전체를 USB에 풀고 실행하세요. 프로그램과 Data 폴더를 항상 함께 보관하세요. ‘저장하고 종료’로 앱을 닫은 뒤 Windows의 ‘하드웨어 안전하게 제거’를 사용하세요. 이 버튼은 USB 장치를 꺼내는 기능은 아닙니다.
팀원·질문·답변은 함께 이동합니다. 새 PC의 로그인은 다시 필요할 수 있어요. 팀 기록과 웹 쿠키는 보관함 비밀번호로 보호합니다. 다운로드·내보낸 기록·CLI 파일·이전 버전 원본은 암호화되지 않아요. 신뢰하는 PC에서 사용하고 별도 백업도 보관하세요.
Claude 개인 계정은 만 18세 이상용입니다. Gemini는 국가와 계정 종류에 따라 연령·보호자 승인 조건이 달라요. 개인정보는 질문에 넣지 말고, AI의 답은 함께 확인하세요.

USB · 암호화 보관함

      
보관함 잠금 해제

      
마스터 비밀번호로 팀 기록과 세션 보관함을 열어 주세요.

      
      
      
이전 버전 기록을 암호화 보관함으로 복사합니다. 기존 JSON·Browser 폴더와 백업은 보존되며 자동으로 암호화되지 않습니다. 완전한 보호가 필요하면 새 USB 폴더에서 시작하세요. 이전 로그인은 다시 해주세요.

      
12자 이상으로 설정하세요. 비밀번호를 잊으면 복구할 수 없습니다. 웹 세션 복원은 기기 인증·만료에 따라 실패할 수 있어요. 웹과 CLI는 별도로 로그인하며 CLI 로그인 정보는 이 보관함으로 옮기지 않습니다.

      

      
      
    

  
  

  
    

      
로그인 전 설정

      

      
      
이 동의는 다른 팀원이 사용량 소진을 표시해 내게 미션을 넘길 때, 화면에 보이는 5초 타이머(언제든 취소 가능) 뒤 질문을 클립보드에 복사하고 내 웹창을 여는 것까지만 허용해요. 질문 자동 전송, 로그인 대행, CLI 계정 사용에는 동의하지 않은 것이며 앱은 로그인 여부를 확인하지 않습니다. 팀원 카드의 ‘자동 인계 설정’에서 언제든 끌 수 있어요.

      

      

    

  
  
    

      
사용량 소진 · 다음 팀원에게 인계

      
원래 담당 팀원이 사용량 소진을 직접 표시했어요. 앱은 사용량을 감지하지 않으며, 인계는 질문 복사와 이어받는 팀원의 웹창 열기까지만 합니다. 로그인 확인·붙여넣기·전송은 이어받는 팀원이 직접 합니다.

      
실행 방식이 CLI여도 인계는 웹창만 엽니다. CLI는 이 PC에 로그인된 계정 하나를 쓰므로 팀원별 계정 분리를 지원하지 않아요.
