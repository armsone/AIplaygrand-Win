AIplaygrand-Win 0.4 · USB에서 함께 배우기

1. ZIP 전체를 USB 폴더에 풀고 AIplaygrand-Win.exe를 실행하세요.
2. 12자 이상의 팀 보관함 비밀번호를 정하세요. 잊으면 복구할 수 없습니다.
3. 팀원의 ‘열기’에서 공식 웹사이트에 직접 로그인하세요.
4. 질문과 팀원을 정하고 웹 또는 CLI 방식으로 미션을 열어 주세요.
5. 질문은 복사됩니다. 직접 붙여 넣고 전송한 뒤 답과 배운 점을 기록하세요.
6. ‘저장하고 종료’를 누르고, 별도로 열린 CLI 터미널도 닫으세요.
7. Windows ‘하드웨어 안전하게 제거’ 후 USB를 옮기세요.

exe만 옮기지 말고 프로그램 전체와 Data를 함께 유지하세요.
웹 사용은 CLI 설치가 필요 없습니다. CLI가 없으면 실행 준비에서 공식 설치 안내를 이용하세요.
Node.js 20 이상과 npm이 준비되면 CLI ‘USB에 설치’가 가능합니다.
설치 터미널을 열었다고 설치가 끝난 것은 아닙니다. 끝난 뒤 ‘다시 점검’하세요.

웹 팀원 이어받기: 각 팀원 로그인 설정에서 명시적 동의(기본 꺼짐) 시 5초 자동 창 열기를 허용하며 team.vault에 암호화 저장됩니다(언제든 철회 가능). 앱의 쿼터 자동 감지는 없으며 사람이 소진을 표시하면 원본은 일시중단·부분답변 보존 후 세션 후보에서 제외됩니다('다시 참여'로 수동 복귀, 실제 쿼터 확인 아님). 로그인·잔여량은 소유자 확인 전까지 미상입니다. 동의 대상은 5초 취소 타이머(다른 대상 선택 시 리셋, 미동의는 직접 이어받기, 취소/포커스 해제/새로고침/종료 시 중단) 후 새 미션 저장 -> 클립보드 복사 -> 전용 웹 창이 열립니다. 제공자 자동 전송 및 CLI 계정 전환은 없습니다.

CLI 팀 릴레이: 작업 하나를 적고 ‘릴레이 시작’을 누르면 세 단계가 차례로 이 PC의 CLI를 자동 실행합니다(단계별 변경 가능).
Claude Code·Codex CLI·Gemini CLI를 앱 안에서 실행합니다. Gemini는 실행 준비에서 앱이 지원하는 0.59.0 버전을 설치하세요. 처음 질문할 때 열리는 Google 로그인창에서 직접 로그인하세요.
릴레이는 텍스트·코드 제안만 받습니다. Claude Code는 도구 없음·safe-mode로, Codex CLI는 읽기 전용 샌드박스로 실행되어 파일 수정은 막히지만 Codex는 읽기 전용 명령을 짧게 실행할 수 있습니다. 웹 미션은 제공자 전송이 여전히 수동 방식입니다(복사·창 열기는 선택적 타이머).
세 단계는 세 계정이 아니라 세 번의 CLI 실행입니다. 같은 서비스를 여러 단계에 쓰면 같은 CLI 계정 하나를 반복 사용합니다. 계정 분리·자동 교체·제한 우회는 없으며 앱은 API 키를 묻지 않습니다.
‘중지’는 언제든 가능하고 부분 결과는 화면에 남습니다. 기록이 20개이거나 보관함 여유가 부족하면 시작하지 않으며 오래된 기록을 자동으로 지우지 않습니다. 앱을 닫으면 릴레이가 중단되며 다시 열어도 자동 재실행되지 않습니다.

CLI 1:1 대화: 실행 준비에서 설치 확인 → 서비스 로그인 → CLI 대화 → 질문 입력과 전송 순서입니다. Claude Code·Codex CLI·Gemini CLI의 답변이 앱 안에 나타나고, 이어 질문하기·중지·복사·이전 기록 보기가 가능합니다. 이전 맥락은 앱이 조합하여 전달합니다(최대 5만 자). 앱이 보관하는 전송 기록은 team.vault에 암호화되지만 전송 전 초안은 저장되지 않습니다. CLI 자체 인증·설정·기록은 해당 도구가 PC에서 관리합니다. Gemini의 앱 전용 CLI 로그인은 이 PC의 앱 데이터 폴더에 남으며 USB로 이동하지 않습니다.

팀 기록과 앱 웹창 쿠키, CLI 릴레이 및 대화 기록은 Data/team.vault에 암호화됩니다.
새 PC에서 쿠키 복원을 시도하지만 로그인 유지는 보장하지 않습니다. 필요하면 다시 로그인하세요.
CLI는 PC에서 로그인한 계정을 사용합니다. 웹 팀원 선택으로 CLI 계정이 바뀌지 않습니다.
CLI 인증·설정은 USB 보관함에 포함되지 않습니다. 다운로드·내보낸 JSON·CLI 작업 파일도 암호화되지 않습니다.
0.2에서 옮긴 원래 JSON과 Browser 파일은 삭제하거나 암호화하지 않으므로 기존 평문이 남습니다.
보관함 암호를 아는 사람은 팀 기록과 세션을 사용할 수 있습니다. 신뢰하는 PC와 팀에서만 쓰세요.
별도 저장소에 종료한 앱 폴더 전체를 정기적으로 백업하세요.
업데이트 전 종료하고 Data를 별도로 백업한 뒤 프로그램 파일만 교체하세요.
