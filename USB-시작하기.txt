2. 팀 보관함 비밀번호를 정하세요. 길이·문자 조합 규칙은 없습니다. 잊으면 복구할 수 없습니다.

4. 질문을 적고 이번 차례와 실행 방식(웹 직접/웹 자동 전송/CLI 대화/공용 터미널)을 선택해 미션을 추가하세요.

6. 한도 도달 시 ‘사용량 소진 · 다음 팀원에게’(수동) 또는 ‘사용량 소진 · 자동 이어받기’(보내는 팀원과 받는 팀원 모두 자동 전송·부분 답변 공유에 동의 시 자동)로 넘기세요.
7. ‘저장하고 종료’ 클릭 → 열린 CLI 터미널 종료 → Windows ‘하드웨어 안전하게 제거’ → Data 포함 폴더 전체 이동 순으로 마칩니다.

웹 팀원 이어받기: 이 수동 경로에서는 앱의 쿼터 자동 감지가 없으며 사람이 직접 소진을 표시하면 원본은 일시중단·부분답변 보존 후 세션 후보에서 제외됩니다('다시 참여'로 수동 복귀, 실제 쿼터 확인 아님). 각 팀원 로그인 설정에서 명시적 동의(기본 꺼짐) 시 5초 취소 타이머 후 창 열기나 이어받기가 진행됩니다. 추가 옵트인 시 인식 가능한 공식 한도에 한해 Claude 웹·Gemini 웹 자동 전송 및 CLI 자동 이어받기가 5초 취소 타이머로 동작하며(실기기 미검증, 알 수 없는 오류는 멈춤), Codex 웹(https://chatgpt.com/codex/cloud)은 코드 환경 설정 확인 전까지 수동 열기·복사를 유지합니다. 프로필별 동의 여부는 team.vault에 암호화 저장됩니다.

CLI 팀 릴레이: 작업 하나를 적고 ‘릴레이 시작’을 누르면 세 단계가 차례로 이 PC의 CLI를 자동 실행합니다(단계별 변경 가능).
Claude Code·Codex CLI·Gemini CLI를 앱 안에서 실행합니다. Gemini는 실행 준비에서 앱이 지원하는 0.59.0 버전을 설치하세요. 처음 질문할 때 열리는 Google 로그인창에서 직접 로그인하세요.
릴레이는 텍스트·코드 제안만 받습니다. Claude Code는 도구 없음·safe-mode로, Codex CLI는 읽기 전용 샌드박스로 실행되어 파일 수정은 막히지만 Codex는 읽기 전용 명령을 짧게 실행할 수 있습니다. 기본 수동 웹 미션은 제공자 전송이 수동 방식이며(복사·창 열기는 선택적 타이머), 옵트인 시 Claude 웹·Gemini 웹 자동 전송을 지원하고 Codex 웹은 수동을 유지합니다.
세 단계는 기본적으로 세 계정이 아니라 세 번의 CLI 실행입니다. 초기 실행에는 별도 자리 선택자를 두지 않고 공용 CLI 계정을 사용하며, 같은 서비스를 여러 단계에 쓰면 같은 공용 CLI 계정 하나를 반복 사용합니다. 3단계 릴레이 실행 중 확인된 쿼터 소진 시, 별도 릴레이 자동 인계 동의(기본 꺼짐)와 소스 독립 자리의 v2 동의 및 동일 제공자 후보 CLI 자리의 v2 동의가 있으면 화면에 보이는 5초 취소 카운트다운 후 실패 단계에서 동일한 runId로 자동 이어받기(runId/task/이전 단계 결과/현재 부분 답변/역할/남은 단계 모두 보존)가 진행됩니다. 카운트다운 중 후보 선택·건너뛰기·취소가 가능하며 창 포커스 해제 시 일시정지됩니다. 후보 자리는 설정된 자리일 뿐 실제 로그인·쿼터 검증 상태가 아니며, 미확인 오류나 인증 실패는 즉시 멈추고 재시도 루프를 돌지 않습니다. 기존 명시적 수동 이어받기(수동 공유 확인 및 대상 v2 동의 필요)도 유지됩니다. 웹과 3단계 릴레이 간 자동 인계는 없으며(동일 제공자 CLI 간만 지원), 시작/새로고침 시 자동 재개되지 않습니다. 앱은 API 키를 묻지 않습니다.
‘중지’는 언제든 가능하고 부분 결과는 화면에 남습니다. 기록이 20개이거나 보관함 여유가 부족하면 시작하지 않으며 오래된 기록을 자동으로 지우지 않습니다. 앱을 닫으면 릴레이가 중단되며 다시 열어도 자동 재실행되지 않습니다.

CLI 1:1 대화: 실행 준비에서 설치 확인 → 서비스 로그인 → CLI 대화 → 질문 입력과 전송 순서입니다. Claude Code·Codex CLI·Gemini CLI의 답변이 앱 안에 나타나고, 이어 질문하기·중지·복사·이전 기록 보기가 가능합니다. 이전 맥락은 앱이 조합하여 전달합니다(최대 5만 자). 앱이 보관하는 전송 기록은 team.vault에 암호화되지만 전송 전 초안은 저장되지 않습니다. 공용 CLI 자체 인증·설정은 PC 로컬에 남습니다. 독립 CLI 자리는 '로그인 보관'·'로그인 복원'·'보관된 로그인 삭제'로 전용 CLI 토큰(Codex auth.json, Gemini oauth_creds.json, Claude Windows/Linux .credentials.json)을 보관함에 관리할 수 있습니다.

팀 기록과 앱 웹창 쿠키, 독립 CLI 자리 보관 로그인(선택), CLI 릴레이 및 대화 기록은 Data/team.vault에 암호화됩니다.

공용 CLI는 PC에서 로그인한 계정을 사용합니다. 팀원별 격리가 필요하면 ‘독립 CLI 자리’를 생성하세요. 웹 팀원 선택으로 공용 CLI 계정이 바뀌지 않습니다.
새 PC 이동 시 공용 CLI 인증은 로컬에 남아 이동하지 않습니다. 독립 CLI 자리는 '로그인 보관'·'로그인 복원'·'보관된 로그인 삭제' 제어로 암호화된 Data/team.vault에 보관할 수 있습니다. 캡처 대상은 Codex auth.json, Gemini oauth_creds.json, Claude Windows/Linux config/.credentials.json에 한정되며(Mac Claude 키체인 이동 미지원, 전역 키체인/타 앱 시크릿 가져오기 없음), 복원은 빈 동일 자리 PC 경로에만 가능하고 기존 로그인을 덮어쓰지 않습니다. 모든 작업은 사용자 확인 후 수행되며, 로그인 캡처(보관) 전 열려 있는 모든 CLI 터미널을 반드시 닫아야 합니다. 저장된 토큰 만료/회전에 대비해 PC 이동 전 백업을 갱신하고 단일 활성 PC를 권장합니다. 복원된 PC 파일은 OS 사용자 권한의 공식 CLI 평문 저장소이며 앱 암호화가 PC 사본을 보호하지 않습니다(보관함 .bak에 삭제 복사본이 남을 수 있음). 다운로드·내보낸 JSON·CLI 작업 파일은 암호화되지 않습니다.

휴대용 자체 업데이트(Windows x64 전용, 실기기 미검증): 0.5.0에는 업데이터가 없습니다. 업데이터가 들어간 첫 버전은 0.6.0이며, 이 버전은 ZIP을 직접 내려받아 프로그램 파일을 한 번 바꿔 넣어야 하고, 그다음 버전부터 앱 안에서 업데이트할 수 있습니다.
    - 시작할 때 한 번(잠금 화면 포함)과 '업데이트 확인' 버튼으로 새 버전을 확인하고 '나중에(기본)'/'지금 업데이트'를 묻습니다. 동의 전에는 내려받지 않습니다.
    - 공식 GitHub 릴리스 주소에서만 받고 GitHub이 자산에 붙인 SHA-256과 크기를 검증합니다(공식 HTTPS에서 받은 그 파일인지 확인하는 것이며 코드 서명 검증은 아님). 파일은 실행 파일 옆 .aiplaygrand-update\<UUID>\ 에 둡니다.
    - 준비가 끝났을 때 진행 중인 작업(대화·릴레이·웹 자동 전송·이어받기·미저장 결과)이 없으면 평소의 '저장하고 종료'를 자동으로 실행하고, 작업 중이면 끊지 않고 '업데이트 적용' 버튼으로 바뀝니다. 저장이 모두 끝난 뒤에만 승인하며, PowerShell 5.1 도우미는 앱이 실제로 종료된 뒤 프로그램 파일만 교체하고 다시 시작합니다. Data(보관함·로그인·기록)·Tools·사용자 파일은 건드리지 않습니다.
    - 교체 전 원본은 .aiplaygrand-update\<UUID>\backup 에 남고, 파일을 옮기기 전과 후에 저널을 기록합니다. 실패하면 저널 표시만 믿지 않고 제자리 파일과 백업의 실제 해시를 대조해 되돌리며, 모든 파일이 원본 상태임을 다시 확인했을 때만 이전 버전을 다시 엽니다. 백업은 어떤 경우에도 자동으로 지우지 않으므로 USB 공간을 차지합니다.
    - 앱이 다시 열릴 때까지 USB를 빼지 마세요. 교체 중 전원이 꺼지면 다음 실행 때 복구 안내가 뜨며, 그 폴더의 apply-update.ps1 을 -Action Recover 로 실행해 되돌리기를 다시 시도할 수 있습니다(FAT/exFAT·전원 차단에서 완전한 복구를 보장하지는 않으니 업데이트 전 폴더 전체를 복사해 두세요).
    - 관리자 권한 요청, 실행 정책 변경, Bypass 우회를 쓰지 않습니다. PowerShell 실행 정책이 스크립트를 막는 PC에서는 그 사실만 표시하고 기존 버전을 그대로 둡니다(ZIP을 직접 내려받아 교체). 도우미에는 Windows PowerShell 5.1과 .NET Framework 4.7.2 이상이 필요하며, 더 오래된 .NET에서는 준비 단계에서 중단하고 안내합니다. Mac은 지원하지 않습니다.
